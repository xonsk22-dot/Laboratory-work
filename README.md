## Задача 1 - Калькулятор площади треугольника
Программа вычисляет площадь треугольника по трём его сторонам (по формуле Герона) с точностью до сотых.
## Среда разработки
Язык программирования: Python.
Среда разработки: PyCharm Community Edition 2024.3.1.1
## Инструкция по работе
По запросу программы необходимо ввести три числа — длины сторон треугольника. Числа могут быть как целыми, так и дробными. После ввода программа вычислит площадь треугольника по формуле Герона и выведет результат с двумя знаками после запятой.

## Задача 2 - Конвертер единиц измерения расстояния
Программа-конвертер, которая переводит расстояние из одних единиц измерения в другие. Программа поддерживает следующие единицы: Километры (км), Метры (м), Сантиметры (см), Миллиметры (мм), Мили (mi), Ярды (yd).
## Среда разработки
Язык программирования: Python.
Среда разработки: PyCharm Community Edition 2024.3.1.1
## Инструкция по работе
По запросу программы необходимо выбрать исходную единицу измерения из предложенного списка, затем выбрать целевую единицу измерения и ввести значение расстояния для конвертации. Значение может быть как целым, так и дробным. После ввода программа выполнит перевод и выведет результат.

## Задача 3 - Определение високосного года
Программа определяет, является ли введённый год високосным. Правила определения високосного года: год делится на 4, но если год делится на 100, он не является високосным, однако если год делится на 400, он всё равно считается високосным.
## Среда разработки
Язык программирования: Python.
Среда разработки: PyCharm Community Edition 2024.3.1.1
## Инструкция по работе
По запросу программы необходимо ввести год (целое число). После ввода программа проверит год по правилам определения високосного года с помощью условных операторов и выведет результат — является ли год високосным или нет.
